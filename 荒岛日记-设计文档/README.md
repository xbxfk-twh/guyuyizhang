## 一、黄金主线（一句话）

**你缺什么 → 去哪里拿 → 被什么挡住 → 造什么解开。**
地图以营地为圆心向外辐射：越远越危险、资源越稀有；瞭望台是唯一能"看清远方"的建筑，
每一次升级都是地图的剧情锁——前期缺的东西在近处，后期缺的东西只在远方。

## 二、五条因果链（全游戏骨架）

```
生存链: 燧石→石斧→木材石头→篝火帐篷→鱼竿→鱼→烟熏炉→熏鱼→商队上门
视野链: 石斧→木板→一级瞭望台→草地/荒漠/山洞→兽皮硝石铁矿→装备火药→二级瞭望台
        →山顶/海域→玄铁珍珠→三级瞭望台→对岸遗迹
装备链: 铁矿石露头(石镐)→铁锭→铁斧铁镐→深层铁矿→铁剑铁甲→钢→(山顶)玄铁秘银→顶级装备
贸易链: 缺盐铁→漂流瓶→老潮商船→委托行情→小船→盐镇→声望→情报→结局物资
剧情链: 漂流瓶→荒漠白骨线索→山洞深处石板→山顶祭坛异象→集齐遗物+石板×3+龙骨→结局C
```

**环环相扣的定义**：上一条链的产出，恰好是下一条链的输入；任何一环的解锁条件，
在上一环中一定已经可以获得（详见 `07-流程推演与开发备忘.md` 的逐日验证）。

## 三、三问校验法（本文档所有内容都过了这一关）

每新增一个系统/物品/场景，必须答出三问，答不出第三问就砍掉：
1. 它**消耗**什么？（时间 / 资源 / 风险）
2. 它**产出**什么？
3. **谁**（哪个系统、哪一段流程）**需要**这个产出？

## 四、v2 修订说明（相对 v1 的审查结论）

| 类型 | 问题 | 修复 |
|---|---|---|
| 死锁 | 铁镐需铁锭，但铁矿只能用铁镐采（鸡生蛋） | 石镐可采采石场浅层"铁矿石露头"（少而慢） |
| 矛盾 | 盐镇解锁：02 说三级瞭望台，06 说第 12 天小船即可 | 统一为：瞭2+小船→对岸盐镇区；瞭3→对岸遗迹区 |
| 矛盾 | 季节天数与通关时长不对齐、无循环 | 15 天/季、60 天/年、循环 |
| 冗余 | 场景 16 个 | 压缩为 12 个（沉船湾并入海域副点；盐镇+遗迹合并为"对岸"；删迷雾峡谷） |
| 冗余 | 资源约 45 种（铜/银/珊瑚/丝绸/鹅卵石/骨头/干草/蜂蜡等用途不明） | 42 种，每种都有明确消费者 |
| 冗余 | 异常状态 6 种 / 敌人 21 种 / 商人 8 人 | 状态 4 / 敌人 17（14 普通+3 Boss）/ 商人 5 |
| 复杂 | 行情公式 5 因子 | 4 因子：基准×季节×供需档×声望折扣（±10%随机） |
| 复杂 | "瞎走可提前撞见未解锁区" | 删除，只保留瞭望台一条解锁路径 |
| 补强 | "越远越强"无标准 | 危险等级公式化：距离分+地形分（夜间+1） |
| 补强 | 系统之间无显式关联 | 五条因果链 + 每系统标注"输入/输出/消费者" |
| 补强 | 无法保证不卡死 | 双路径原则（关键物资≥2 条获取路径）+ 逐日推演 D1~D30 验证 |
| 补强 | 沉浸感无标准 | 场景文案三层模板 + 沉浸感九条（见 01） |

## 六、核心参数速查（所有文档共用这一套数，发现冲突以本表为准）

- 时间：1 天=24h；**发呆不消耗时间**，行动消耗 15min~12h；睡觉 5~8h；白天 06-18，夜晚 22-06
- 生存：HP/体力/饱食/饮水/精神 各 100；饥渴归零后每游戏小时 -10HP
- 季节：春 1-15 / 夏 16-30 / 秋 31-45 / 冬 46-60 天，循环
- 解锁：瞭1→草地/荒漠/山洞；瞭2→山顶/海域/盐镇；瞭3→对岸遗迹
- 货币：早期以物易物 → 第 2 次商队起贝壳币 → 后期金币（1 金币=100 贝壳）
- 通关参考：简单 25~35 天，普通 30~45 天，困难 40~60 天，传奇死亡即重开
