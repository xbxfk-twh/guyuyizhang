# 06 美术 · 音乐 · AI 提示词

## 6.1 风格定义（全黑白）

- **视觉**：黑白木刻版画 + 水墨混合质感；高对比、粗犷笔触、纸张噪点纹理；
  画面像"老故事书里的荒岛"——苍凉但不失生机。
- **色彩纪律**：纯黑白灰阶。危险用 描边加粗+墨点 表示，不用红色（坚持你的全黑白要求）。
- **文字风格**：中文衬线体（宋/明朝体），行距宽松，像在读一本旧日记。

## 6.3 AI 绘图提示词库（可直接粘贴）

### 风格定调（先跑 3~5 张选一张做母版）
```
黑白木刻版画风格，荒野孤岛主题，粗犷笔触，高对比度，纸张纹理与噪点，
水墨晕染质感，荒凉孤寂但有生机的氛围，无文字，纯黑白灰阶
```
英文备用（中文效果差时）："black and white woodcut print style, wild deserted island,
bold strokes, high contrast, paper grain noise, ink wash feel, desolate but alive mood,
no text, monochrome grayscale only"

### 全景长卷（最重要的一张）
```

中上方荒漠（枯树与白骨），右上方开阔草地（有动物）；

底部中央小营地（帐篷、篝火、储物箱、帐篷前苗床）；

## 6.4 音乐与音效（9+6，分层混音）

### 环境音层（循环播放）
海浪、风声、虫鸟（昼/夏）、洞窟滴水——随场景切换交叉淡化。

### 主题配乐（5 首，1 分钟循环即可）
| 主题 | 情绪 | 参考乐器 |
|---|---|---|
| 营地 | 安宁温暖 | 木吉他、口琴 |
| 野外（树林/竹林/草地/河畔共用） | 静谧清新 | 竹笛、排箫 |
| 险境（荒漠/山洞/山顶/遗迹） | 苍凉压迫 | 长笛、大提琴、低频嗡鸣 |
| 海域 | 辽阔孤寂 | 钢琴琶音、海浪白噪 |
| 战斗 | 紧张鼓点 | 低音鼓、弦乐断奏 |

### 音效（6 个）
获得物品（墨滴）、危险预警（低钟）、交易成交（铜钱）、升级完成（短促上扬旋律）、
火焰点燃（噼啪）、死亡（一声闷响后寂静）。

### 联动规则
- 昼夜渐变：黄昏起旋律渐弱、风声渐强；
- 天气实时混入：雨声/雷声/风沙；
- 事件先声：危险音效先于文案 0.5 秒（"你听到了什么……"）；
- 结局：主题曲 + 日记回放，情感收束。

│ [交互点列表] 采集·战斗·冒险·事件          │
├──────────────────────────────────────┤
│ 生命/体力/饱食/饮水/精神（6 条墨色条）     │
│ 第 7 天 · 14:30 · 晴   背包 34/60 格     │
└──────────────────────────────────────┘
```

动效克制：雾散、箭头浮现、墨滴涟漪。全部动效黑白。

## 6.6 制作流程（配合你的绘图 AI）

1. 跑风格定调图 3~5 张 → 选定母版风格；
2. 按 6.3 全景提示词出长卷（可分段生成后拼合）；
3. 12 张场景图按模板逐张生成，统一后期滤镜（对比度+噪点）保证一致；
4. 图标/怪物批量生成（换名词跑同一条提示词）；
5. 音乐按 6.4 顺序：先环境音 → 营地/战斗两主题 → 其余三首。
