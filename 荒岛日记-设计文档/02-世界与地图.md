## 2.2 危险等级公式（"越远越强"的数学化）

```
危险等级 = 距离分 + 地形分 + 夜间修正，上限 5
距离分: 近(≤20分钟)1 / 中(21~60分钟)2 / 远(>60分钟)3
地形分: 0 营地·耕地 / 1 水岸·林地·草原·海域 / 2 崖矿·荒漠·洞穴·严寒·遗迹
夜间修正: 野外+1；荒漠/山洞/山顶 夜间再+1（白骨守卫出没）
```
（自检：12 个场景逐一代入公式，结果与 2.3 表危险等级完全一致。）

公式的意义：**未来加新场景不用拍脑袋定难度**，按公式算即可，且永远保持"越远越危险"的大方向。

## 2.4 瞭望台与迷雾（地图的总开关）

| 瞭望台 | 材料/耗时 | 新解锁（箭头出现） | 额外能力 |
|---|---|---|---|
| 未建造 | — | 营地、耕地、河畔、树林、竹林、采石场 | — |
| 一级 | 木杆×8+木板×8+藤蔓×4 / 2h | 草地、荒漠、山洞 | 远望感文案 |
| 二级 | 木板×16+铁钉×8+绳索×2 / 4h | 山顶、海域（含沉船湾）、对岸·盐镇区 | 天气预测 12h |
| 三级 | 石砖×16+铁件×8+帆布×2+望远镜×1 / 8h | 对岸·遗迹区 | 天气预测 24h + 全图资源/危险情报角标 |

规则：
1. **看得见才去得了**：箭头只在对应等级达到后出现，没有其它途径提前解锁；
2. 建造瞭望台 = 当天有 2~8h 的"不可做别的事"窗口，玩家自己选日子（雨天造最划算）；
3. 升级瞬间有仪式感动画：镜头轻微拉远 → 墨雾退散 → 新箭头逐一浮现 → 一段解锁文案。

## 2.5 赶路规则

- 点击箭头 = 出发；途中 1~2 条文字播报；耗时按 2.3 表结算；
- 路遇事件（10% 概率）：偶遇小动物（小收益）/ 拾荒（小资源）/ 无事发生；夜晚概率翻倍且偏负面；
- 减免：路标（-10%）、驯服野马（-30%）；加价：夜晚无火把（+50%，"迷路"文案）；
- 夜晚 22 点后离营需要火把，否则出发前弹警告"夜色吞没了小路……确定要去吗？"。

## 2.6 场景内部结构（每个场景的统一规格）

每个场景 = 1 张插画 + 1 段开场白 + 交互点列表：

```
【树林 · 第 4 天 · 08:30 · 晴】
晨雾还没散，松脂味混着露水。几只鸟在头顶跳来跳去。
  · 老松树   [砍伐：木材×2~4，15min，需斧]      ← 采集点
  · 灌木丛   [采集：浆果×1~2，10min]              ← 采集点
  · 藤蔓坡   [采集：藤蔓×2，10min]                ← 采集点
  · 可疑脚印 [调查：可能触发野猪战斗/追猎线索]      ← 事件点
  · 蜂巢     [冒险：蜂蜜×1，高风险被蛰]            ← 冒险点
  [返回营地 15min]
```

交互点四类：**采集点**（稳定产出，每日日出刷新，富集度 ±30% 随机浮动）、
**战斗点**（敌人+战利品）、**冒险点**（高风险高收益，二选一骰）、**事件点**（剧情/随机事件）。
特殊点（宝箱、遗骸、矿脉）刷新周期 3 天，防止无脑刷。
