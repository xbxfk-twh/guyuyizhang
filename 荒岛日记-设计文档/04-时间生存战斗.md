# 04 时间 · 生存 · 战斗

## 4.1 时间模型（本作的核心规则）

**原则：时间自动流逝极慢（仅"氛围流逝"），只有行动才真正推进时间。**

| 行动 | 耗时 | 消耗 |
|---|---|---|
| 采集一次 | 10~30min | 体力 -15~20 |
| 战斗一场 | 20~40min | 体力 -30~50 |
| 赶路 | 见 02-2.3（5~120min） | 体力 -5/15min |
| 制造/建造 | 30min~16h（见 03） | 体力 -10/小时 |
| 烹饪/制药 | 20~40min | 体力 -5 |
| 交易 | 30min~1h | 体力 -5 |
| 休息 | 1h/次 | 体力 +10 |
| 睡觉 | 5~8h（床越好越短） | 体力回满、生命+30、精神+15 |

### 每日时间预算验证（证明"一天能做的事"足够）

- 清醒时间 16h = **960 分钟**。
- 标准一天：赶路往返 60min + 采集 5 次 100min + 战斗 1 场 30min + 制造 2h + 吃饭 30min + 睡觉 8h
  = 820min ≈ 13.7h ✓ **每天有 2~3 小时弹性**，玩家有余裕，但不足以做所有事——取舍感成立。
- 远征日：赶路荒漠往返 90min + 采集 3 次 60min + 战斗 1 场 30min + 制造 1h + 睡觉 8h
  = 500min 活动 ≈ 8.3h，一天只能做一次远征 ✓（"远"因此昂贵，与"越远越稀缺"互相咬合）。

### 昼夜

| 时段 | 规则 |
|---|---|
| 06~18 白天 | 正常行动 |
| 18~22 黄昏 | 视野-30%；战斗/采集效率 -10% |
| 22~06 夜晚 | 野外危险 +1（荒漠/山洞/山顶 +2）；无火把赶路 +50% 耗时；建议回营 |
| 熬夜 | 效率 +30%，但精神 -15、次日体力上限 -30% |

### 季节（15 天/季，60 天/年，循环）

| 季节 | 天数 | 影响 |
|---|---|---|
| 春 | 1~15 | 采集+10%；竹笋季 |
| 夏 | 16~30 | 口渴加剧；海产丰富；风暴季（出海风险+） |
| 秋 | 31~45 | 浆果坚果成熟；皮毛质量好；最优远征季 |
| 冬 | 46~60 | 采集-40%；需保暖（无暖装野外持续掉血）；河面结冰（冰面捷径+冰窟风险）；兽皮行情↑ |

### 天气（每日日出掷一次）

| 天气 | 影响 |
|---|---|
| 晴 | 正常 |
| 阴 | 效率 -10% |
| 雨 | 采集-30%；生火成功率-50%；蘑菇/草药刷新+；可接雨水；河流涨水（漂流物+） |
| 雾 | 赶路+50%；隐藏事件概率+ |
| 雷暴 | 采石场/山顶/出海禁止；全岛闪电声氛围 |
| 雪（冬） | 采集-40%；结冰；保暖需求+ |

**信息闭环**：二级瞭望台预测未来 12h 天气、三级 24h——"今天晴天，适合远征"成为玩家的真实决策。
雨天在家制造、晴天出门采集，天气让时间管理有了变量。

## 4.2 生存细节规则

- 饱食/饮水每小时自然 -2，行动额外 -5~-10（饮水降得更快）；
- 食物有保鲜期（见 03-3.5），吃变质食物 → 中毒；
- 体温 = 衣物保暖 + 建筑保暖 + 篝火范围；冬季野外无毛皮大衣每小时 -5HP；
- 精神 < 30 触发"幻觉事件"（看到不存在的东西，可能是真的也可能是假的——文字游戏的乐趣点）；
- 受伤（HP<30%）：采集/战斗效率 -30%，需草药膏或睡觉。

## 4.3 战斗系统（轻量回合制，2~5 回合定胜负）

### 属性
玩家：攻击（武器）、防御（防具）、速度、命中率、暴击率。
敌人：HP/攻/防/速 + 1 个特性。

### 每回合指令（5 选 1）
| 指令 | 效果 |
|---|---|
| 攻击 | 常规伤害，速度高先手 |
| 重击 | 伤害×1.5，命中-20%（战斗经验 Lv2 解锁） |
| 防御 | 本回合减伤 60%，体力+10 |
| 道具 | 药品/火把/陷阱（每战限 2 次） |
| 逃跑 | 成功率=50%+速度差；失败白挨一击 |

### 结算与后果
- 胜利：战利品+战斗经验；HP 低于 20% 胜利 = "险胜"日记（沉浸感奖励）。
- 失败：HP 归零 → 按难度回退（01-1.5）；营地夜袭失败则额外损失部分储物。
- 先手提示：战斗前显示一行预警文案（"狼群在你下风向，还没发现你——打还是撤？"）。

### 异常状态（仅 4 种，每种都有解药，闭环）

| 状态 | 效果 | 解除 |
|---|---|---|
| 流血 | 每回合 -5HP | 止血绷带、睡觉 |
| 中毒 | 每回合 -3HP×5 回合 | 解毒剂 |
| 寒冷 | 速度-30%、每回合 -2HP（冬/山顶） | 篝火、暖汤、毛皮大衣 |
| 恐惧 | 命中-30% | 提神茶、回营地 |

## 4.5 营地夜袭（防御战）

- 每晚概率：无墙 5% → 栅栏 3% → 木墙 1% → 石墙 0.5%；D7 首次触发为教学事件。
- 结算：**自动战斗简报**（防御值+玩家装备 vs 来袭强度），不强制深夜操作；
- 可主动"守夜"：不睡觉，防御 ×2 且改为手动战斗，但次日精神-15、体力只回 50%。
- 损失规则：失败 → 储物随机损失 10~20%，围墙耐久 -1 级（可修）。

## 4.6 战斗数值基准（调参锚点）

- 玩家初始：HP100 / 攻5 / 防2 / 速10；战斗经验每级 HP+8、攻+1、速+0.5。
- 目标曲线：同区域普通怪 = 当前装备 2~3 回合胜；精英（狼群）= 需药或选对指令；Boss = 需针对性准备。
- 伤害公式（简单）：`伤害 = max(1, 攻×技能系数 − 敌防)`，暴击×1.5（基础 10%）。
