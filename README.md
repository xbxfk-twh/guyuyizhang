# 孤屿遗章

中文网页文字生存游戏。纯 HTML / CSS / JavaScript，**无框架、无构建步骤**——双击 `孤屿遗章-游戏 - 发布/index.html` 就能玩。
黑白木刻版画风（隐藏角色"灵灰"是彩色的）。两张地图：孤岛（第一章）、亚特兰蒂斯（第二章）。

> 目前由一个人在做，在 TapTap 上发布。想找人一起做，所以把源码整理成可以被别人接手的形状。

## 怎么跑起来

```powershell
# 直接玩（推荐用本地小服务器，避免某些浏览器对 file:// 的限制）
cd 孤屿遗章-游戏 - 发布
python -m http.server 8000      # 然后浏览器打开 http://localhost:8000

# 或者直接开文件
start index.html
```

不需要 npm / 不需要编译。所有逻辑都在 `js/` 里，改完刷新页面即可。

## 目录结构

```
孤屿遗章-游戏 - 发布/      ← 游戏本体（打包只打这一层）
  index.html               入口（BUILD_VER 是缓存版本号）
  js/data.js               全部数据：物品 / 配方 / 场景 / 敌人 / 成就 / 技能树 / 公告
  js/game.js               主逻辑：时间、采集、战斗、存档、云存档、技能树
  js/ui.js                 界面渲染：地图、弹窗、技能树树状图、日志
  js/audio.js              音频（音乐/音效/环境音三条独立总线）
  css/style.css            样式（全站一套）
  assets/img/              图片资源（约 350 张：场景、道具、敌人、立绘、图标、分镜）
回归测试/audit.js           ★ 全量回归（800+ 条断言），改动后必须全绿
回归测试/checks.js          断言正文
开发工具/生成/              出图与后处理脚本（走环境变量读 key，别写死）
开发工具/检查/              各种专项探针（存档、云存档、技能树、地图、战斗…）
开发工具/打包/_pack.py       打包脚本（产出发布 zip）
文档/                      设计文档、改动记录、更新公告
```

## 改动流程（很重要）

1. 改完代码，**先跑回归**：
   ```powershell
   node 回归测试\audit.js        # 期望：通过 N 项，失败 0 项
   node 开发工具\检查\_smoke_test.js
   node 开发工具\检查\_audit_announcement.js
   ```
2. 涉及界面/美术，自己截图看：`开发工具\截图\_shot.js` 或 `开发工具\检查\_preview_anim.js`。
3. 存档安全是底线：任何改动都不许让老存档读不出来（`S.skill` / `S.exp` 这类老字段语义不能变，只能**新增**字段并写迁移）。
4. 打包：`node 开发工具\生成\_bump_version.js v1.xx` → `python 开发工具\打包\_pack.py`。

## 三条规矩（这个项目踩过的坑）

- **存档只加不改**：老玩家 99% 的存档是好的，宁可写迁移逻辑，也不动老字段含义。
- **密钥不进仓库**：出图/接口 key 一律走环境变量（`$env:DASHSCOPE_API_KEY='sk-...'`）。
- **触发类效果都写日志**：玩家要看得见"刚刚触发了什么"（暴击、吸血、处决、修补匠…）。

## 想一起做？可以接手的方向

| 方向 | 需要的技能 | 从哪儿开始 |
| --- | --- | --- |
| 数值平衡 | 会看数据、愿意试玩 | `js/data.js` 的 `RECIPES` / `ENEMIES` / `SKILL_TREES`，跑 `开发工具\检查\_sim_skill.js` |
| 新技能 / 新机制 | JS | `SKILL_TREES` 加节点 + `game.js` 里按 id 挂钩子 + 补断言 |
| 界面美化 | CSS | `css/style.css`；现有风格：直角、细边框、纸色底、黑白木刻 |
| 美术 | 会画/会用 AI 出图 | 规格见 `文档\立绘卡面_制作说明.md`、`文档\开场分镜_制作说明.md` |
| 剧情/文案 | 中文写作 | `js/data.js` 里的场景描述、事件文本、结局文本 |
| 测试 | 愿意玩 | 跑 `回归测试\audit.js`，把复现步骤写成 issue |

提 PR 之前请确保 `node 回归测试\audit.js` 全绿；新增功能请**同时补断言**。
