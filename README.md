# 孤屿遗章

支持中英文切换的网页文字生存游戏，纯 HTML / CSS / JavaScript，无框架、无编译步骤。第一章为孤岛，第二章为失落的海底文明。整体采用黑白版画风，灵灰与既有彩色皮肤、限定物保留各自表现。

## 运行

在项目根目录执行：

```powershell
python -m http.server 8000 --bind 127.0.0.1 --directory "孤屿遗章-游戏 - 发布"
```

浏览器打开 http://127.0.0.1:8000 。也可直接打开游戏目录的 index.html，但本地服务器更适合检查资源加载。

游戏源码只修改 `孤屿遗章-游戏 - 发布/`。`js/data.js` 定义数据，`js/features/` 放已迁出的功能规则，`js/storage/` 放存档事务与编解码，`js/ui/` 放DOM提交、输入、面板注册及功能视图；`game.js`、`ui.js` 仍承载待迁移领域。`audio.js` 管理音频，`css/` 提供样式。

运行入口以 `runtime-manifest.json` 为单一清单。新增脚本后运行 `node 开发工具/生成/_sync_runtime.js` 同步静态HTML，无须编译或在运行时请求清单；测试加载器与打包校验也读取该清单。

## 检查

```powershell
node 回归测试/run.js
# 涉及界面时，同时运行独立浏览器中的全场景检查
node 回归测试/run.js --browser
```

完整日志在 `回归测试/_out/`。核心检查包含全量回归、玩家反馈专项、集成冒烟、综合核对、存档安全和公告检查；--browser 增加场景与手机触控/启动故障测试；失败返回非零退出码。测试数量以运行输出为准。

[GitHub 自动检查](https://github.com/xbxfk-twh/guyuyizhang/actions/workflows/verify.yml)在推送和 PR 时运行核心、发布校验及重点浏览器检查，保留日志与截图。自动检查不会打包、部署或改写玩家存档。

存档兼容是底线：保留旧字段语义，新增字段须处理旧档缺省情况。密钥通过环境变量读取，私人档案和个人运维工具不纳入版本控制。
