# 目录与工具说明

## 源码与支持工程

```text
孤屿遗章/
├─ 孤屿遗章-游戏 - 发布/   唯一游戏源码；打包仅取此目录
│  ├─ index.html           入口、唯一版本定义
│  ├─ runtime-manifest.json 运行加载顺序
│  ├─ js/data.js           游戏数据
│  ├─ js/features/         已迁出的领域规则
│  ├─ js/storage/          本地、平台、服务器备用与迁移
│  ├─ js/ui/               DOM提交、输入、面板和功能视图
│  ├─ js/game.js、ui.js    仍在拆分的领域入口
│  └─ css/、assets/        样式与实际运行资源
├─ 回归测试/               正式测试、helpers、fixtures
├─ 开发工具/
│  ├─ 检查/               核心、专项和历史诊断探针
│  ├─ 生成/               版本、清单、素材生成工具
│  ├─ 打包/               _pack.py、_verify_zip.py
│  ├─ 预览/               效果实验
│  └─ 存档服务/           独立 Python/SQLite 备用服务
├─ 安卓包装/               Android 原生外壳及构建说明
├─ 官网/                   独立官网、下载页及标准库后端
├─ 文档/                   维护、验收、发布、玩法与协作
├─ 荒岛日记-设计文档/      第一章历史参考
├─ 亚克兰蒂斯-设计文档/    第二章历史参考
└─ .github/workflows/      只读验证与证据归档
```

目录结构与相对路径是现有脚本接口的一部分，不为了外观把大量脚本机械挪动。新功能应进入对应职责目录；删除或迁移旧文件前核实动态调用、测试入口和存档兼容。

## 命令与副作用

| 命令或位置 | 用途与边界 |
| --- | --- |
| `node 回归测试/run.js` | 核心回归；模拟或临时存储 |
| `node 回归测试/run.js --browser` | 全套隔离 Chrome；有已知历史失败，见维护现状 |
| `--browser --only=<脚本名>` | 只选匹配专项；不得当成完整验收 |
| `python -X utf8 回归测试/test_release.py` | 在临时目录校验微型测试发布包 |
| `python -X utf8 开发工具/打包/_pack.py --check` | 只读检查，不生成发布包 |
| `开发工具/打包/_pack.py` | 写发布包；只有作者明确要求打包才运行 |
| `开发工具/生成/_sync_runtime.js` | 根据运行清单改写 HTML 脚本列表 |
| `开发工具/检查/_verify_*` | 专项探针，部分旧脚本仍可能依赖历史环境，先看说明 |
| `_debug_*`、`_dead_code.js` 等 | 历史诊断，不是可直接执行的删除清单 |
| 素材生成工具 | 可能写图片或调用收费服务，不能作普通检查批量运行 |

## 本地与线上数据

`回归测试/_out/`、工具 `_out/`、APK/ZIP、Gradle 输出、网站数据库、服务器快照和签名密钥均不进 Git。历史发布包、私人交接和个人运维工具在本机保留，公开仓库不承载这些内容。服务器代码与测试进入 Git，生产配置和数据库单独管理；普通 CI 不连接生产服务。
