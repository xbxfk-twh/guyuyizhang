# 05 交易与剧情（本文档重点）

> 目标：让"交易"不只是买卖，而是**推进剧情的钥匙**；让"剧情"不只靠读文本，而是**由交易与探索亲手拼出来**。
> 全篇遵循一条主线：**打下去 → 带上来的东西，会改变岸上的人怎么看你、怎么对你说话。**

## 5.1 交易对象（一张网，五个口袋）

| 对象 | 位置 | 收什么 | 卖什么 | 剧情作用 |
|---|---|---|---|---|
| 老潮商船 | 孤岛·营地 | 熏鱼/兽皮/珍珠 | 盐、铁锭、种子、图纸 | 第一章引路人；提到"海的深处" |
| 盐镇·杂货 | 对岸 | 鱼/萝卜/蜜 | 种子、布、绳 | 基础补给 |
| 盐镇·铁匠 | 对岸 | 铁矿/木炭/金矿 | 钢、武器、图纸 | 第一章终局装备 |
| **盐镇·情报贩子** | 对岸 | **亚克兰蒂斯遗物** | **图纸 + 「低语」线索** | **第二章剧情核心** |
| 黑市·独眼 | 沉船湾(夜) | **远古装置** | 禁品、图纸 | 高风险高回报的反向交易 |

## 5.2 图纸经济：三向咬合（环环相扣的骨架）

```
  图纸(吃什么) ──需要──> 材料(从哪来) ──需要──> 深度(装备) ──需要──> 图纸(吃什么)
        ↑                                                                    │
        └────────────────────  特产卖给外岛  ←─────────────────────────────┘
```

1. **深海装备图纸（bpDive）** 是"潜水服 + 氧气罩"的钥匙。
   - 来源①：盐镇情报贩子（`beibi` 贝壳币购买）
   - 来源②：海盗头目 **小概率掉落**（可反复讨伐）
   - 来源③：黑市独眼
2. **海图减半**（300 → **150 金币**）：让"海路进入"成为**不依赖结局**的另一条门（不需通关任何结局）。
3. **图纸—材料**咬合：`图纸 → 潜水服/氧气罩 → 才能下潜 → 才有深珊瑚/源质 → 才能做珊瑚/源质装备 → 才能进更深 → 才有远古装置` → 装置再换更高级图纸/线索。

## 5.3 亚特兰蒂斯「回声交易」（新意 1：把特产变成线索）

情报贩子不只卖图纸，他还**痴迷于亚克兰蒂斯的遗物**。每交给他一件**发光远古装置**，他会"翻译"出一段 **低语（Whisper）**：

| 交出装置 | 他的低语 | 解锁 |
|---|---|---|
| 第 1 件 | "这不是装饰……这是**钥匙**。城里还有同一套的锁。" | 提示圣殿之门 |
| 第 2 件 | "刻文说，灯塔烧的不是油，是**记忆**。" | 开启"归还遗物"支线 |
| 第 3 件 | "有人**已经**下去过——而且没打算回来。" | 揭示沉没之王身份 |
| 集齐 N 件 | "……你是来**归还**的，还是来**搬空**的？" | 触发**两条结局走向**（见 5.5） |

**设计意图**：装置既是"高级材料"又是"剧情道具"，玩家每卖一件都在**用资源换真相**，形成"再下去一趟"的强动机。

## 5.4 行情与风险（新意 2：让"卖"有策略）

- **潮汐行情**：深珊瑚 / 珍珠粒 / 源质 在盐镇的收购价按"传闻与潮汐"**每日浮动**（±30%），玩家可囤货择时卖出。
- **黑市的反向代价**：独眼对"远古装置"出价极高，但每交易一次，**海盗注意度 +1**；注意度满 → 海盗头目提前来袭（既是威胁，也是**刷图纸**的机会）。
- **商船抢单**：老潮偶尔挂出"亚克兰蒂斯特产订单"（委托），完成给 `beibi` 与 **图纸**——把第一章的老潮也拉进第二章的交易网。

## 5.5 剧情主线（章节化，由交易与探索共同推进）

**引子（承接结局 C）**：山顶祭坛点亮，主角读出"文明最后的哨站"，海深处传来低语，**传送石**浮现。

1. **第一幕 · 落脚**：抵达礁石栖息地。发现"会呼吸的城"——珊瑚在夜里发光，像在**回应**你。
2. **第二幕 · 碑文**：第一章的三块**石板**在亚克兰蒂斯有对应碑文；**遗物/龙骨**与圣殿呼应。拼出"灯塔—哨站—沉没"的往事。
3. **第三幕 · 低语（交易驱动）**：把**远古装置**交给情报贩子，逐条换来低语，指向"**重启灯塔**"。
4. **第四幕 · 守护者**：机械守卫现身——它们不是敌人，是**文明的守墓人**（不还遗物，它们就阻你）。
5. **终幕 · 两条走向（新意 3：归还 or 搬空）**：
   - **归还者结局（推荐/主题结局）**：把**遗物 + 石板 + 龙骨 + 装置**归还圣殿 → 重启灯塔 → **结局 S「重燃文明」**。
   - **掠夺者结局（暗线）**：把全部文明遗物**卖光** → 灯塔无法点燃，海沟永暗 → 解锁隐藏结局「空城」（悲剧向）。
   > 同一张地图，两种结局，取决于你在**交易里做了几次"卖"和几次"还"**——这正是"交易即剧情"。

## 5.6 支线与伏笔（把角色与文明缝起来）

- **灵灰**（鲸鱼娘）：在亚克兰蒂斯触发专属台词——她是"海的孩子"，对城市有莫名的熟悉。**伏笔她与文明的渊源**（后续可展开）。
- **老潮的漂流瓶**：第二章追加信件，提到"海的深处"与"不愿提的名字"。
- **石板碑文**：与第一章石板可**拼合**成完整故事（考古式拼图）。
- **小满**（若在第一章救过）：会提醒你"夜里的低语"。

## 5.7 环环相扣总图（交易 ↔ 剧情 ↔ 玩法）

| 你在做的事 | 立刻得到 | 下一步被打开 |
|---|---|---|
| 凑 bpDive 图纸 | 潜水服/氧气罩 | 能下潜（浅层） |
| 浅层采深珊瑚/珍珠 | 珊瑚装备 + 护目镜料 | 中层（洞窟/海沟） |
| 海沟采源矿 | 源质熔炉产物 | 强光手电 → 深海 |
| 深海拿远古装置 | 精炼料 **或** 卖给情报贩子 | **低语线索 / 高级图纸** |
| 交装置换低语 | 剧情推进 | 圣殿之门 / 归还支线 |
| 击败沉没之王 | 源质重甲 | 灯塔仪式 → 结局 S |

**一句话总结**：**每一次下潜产出，都能在岸上换成下一段深度或下一段真相**——这就是第二章"停不下来"的原因。
