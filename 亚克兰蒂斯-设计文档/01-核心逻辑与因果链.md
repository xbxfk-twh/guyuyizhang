# 01 核心逻辑与因果链

## 1.1 一句话玩法

文字驱动、黑白沉浸的**深潜探索**：**凑齐图纸与装备 → 下潜 → 用照明与水压换深度 → 采料/战斗 → 回礁石栖息地加工 → 更深、更强、更接近真相 → 重启灯塔。**
目标不是"刷数值"，而是**沿着五条因果链一步步把一座沉没文明点亮**。

## 1.2 核心循环图

```
┌───────────────────────────────────────────────────────────────┐
│ ① 准备（孤岛/外岛）：凑图纸、做潜水服与氧气罩、囤深珊瑚补给     │
│      ↓ 进入亚克兰蒂斯（传送石：瞬移·免游泳｜海路：游泳1.5h）     │
│ ② 落脚（礁石栖息地）：独立营地，装备消耗减半，可建造/睡觉/修补    │
│      ↓ 打开大地图，点箭头移动（越远越久，虚线动画）             │
│ ③ 探索（各区域）：采集/狩猎/机关（消耗时间+体力，扣氧气耐久）    │
│      ↓ 产出：源矿/深珊瑚/珍珠粒/远古装置                        │
│ ④ 加工（礁石栖息地）：珠光工作台制造、源质熔炉精炼、修补台修装    │
│      ↓ 用新装备解锁更深的区域                                  │
│ ⑤ 深入：珍珠洞窟→海沟→深渊→深水圣殿→击败沉没之王→重启灯塔(S)   │
│      ↓ 特产带回外岛交易 → 换图纸与「低语」剧情                  │
│ ⑥ 回到 ① —— 这次你能潜得更深、更久、更远                       │
└───────────────────────────────────────────────────────────────┘
```

**循环驱动力**：每次下潜都受**时间（氧气耐久）与深度（装备）**双重约束，"这次能到多深"随装备成长而推进，玩家的决策依据每天都在变。

## 1.3 五条因果链（全文最重要的一张图）

|---|---|---|---|---|---|---|
| 探索链 | 秘辛仪式/海图 | 潜水服+氧气罩 | 礁石栖息地 | 浅层(城/珊瑚/沉船/森林) | 深珊瑚+珍珠粒 | 护目镜→洞窟 |

## 1.4 "环环相扣"实现规则

1. **单向咬合**：每条链的下一环，其材料必然来自上一条链的产物（例：护目镜要深珊瑚 → 深珊瑚来自浅层 → 浅层不需照明）。
2. **绝不死锁**：任何"门槛道具"的原料，必须能在**不需要该道具**的区域获得（护目镜的原料来自免照明区，详见 04）。
3. **深度阀门**：区域分 浅/中/深 三档，分别由 潜水服耐压 + 照明道具 双重解锁，保证"先浅后深"。
4. **交易反哺**：外岛只收亚克兰蒂斯特产，用它换**图纸**，图纸再解锁更深的装备——形成"打→卖→换图纸→更能打"的闭环。
5. **剧情即交易**：把特产卖给特定 NPC，会解锁关于失落文明的**低语线索**，把交易链与剧情链缝在一起（详见 05）。
