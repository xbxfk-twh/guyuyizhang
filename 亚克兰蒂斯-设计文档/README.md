## 第二章一句话

在孤岛尽头读完「秘辛」之后，主角循着海底的低语，下潜到沉没的**亚克兰蒂斯**——一座仍在发光的失落文明。
用**潜水服**换深度、用**照明**换黑暗、用**亚特兰蒂斯的特产**向外岛换取图纸与真相，最终重启「灯塔」。

## 设计三原则

1. **越深越贵**：深度由装备（潜水服耐压 + 照明）解锁，深度越高，敌越强、料越稀、剧情越核心。
2. **特产换线索**：亚克兰蒂斯的产物不只是材料，还是**对外岛 NPC 说真话的钥匙**——交易即剧情。
3. **每环都咬合**：任何一件新装备的材料，必然来自上一条链的产物，绝无"凭空起步"或"死锁"。
