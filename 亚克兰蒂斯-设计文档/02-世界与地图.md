# 02 世界与地图

## 2.1 大地图（独立第二张全景图）

亚克兰蒂斯是一张**独立全景大地图**（3:2 横卷，黑白版画风），和孤岛互相独立：两张图各自有场景与热点，**只有背包互通**。
进入亚克兰蒂斯后，地图视图自动切换为这张大地图。

```
 ┌──────────────────────────────────────────────────────────┐
 │   [珍珠洞窟]                        [珊瑚森林] [礁石栖息地] │
 │        \                               \        /         │
 │  [沉船墓地]——[珊瑚生长带]——[沉没之城]——[海沟]            │
 │                                    \            \         │

   越靠右下 = 越深 = 敌人越强 = 资源越稀有 = 剧情越核心
```

## 2.3 移动规则（与第一章共用同一套"大地图逻辑"）

1. 在大地图上点**区域箭头** → 弹**确认弹窗**（显示"耗时 X 分钟 · 消耗体力 Y"）→ 播**虚线连线 + 白点移动**动画 → 到达。
2. **耗时按距离计算**：`分钟 = clamp(距离 × 2.4, ≥15)`，越远越久；体力 = `ceil(分钟/15)×5`。
3. 岛屿与海底的**来回**：传送石（瞬移、免游泳）；海路/返回孤岛 = 游泳 **1.5 小时**。

## 2.4 深度分级（数值化，未来加区域照此推）

```
所需潜水服耐压 = 浅1 / 中2 / 深3      （潜水服等级决定"能到多深 = 水压承受"）
所需照明       = 无 / 护目镜 / 弱光 / 强光（照明决定"黑暗里能否看清、能否采"）
缺失时：进不去（超出水压）或采样失败并扣血（太黑，水压伤害递增）
```

## 2.5 天气与昼夜（海底不适用）

- 亚克兰蒂斯**不受四季与天气影响**：无雨天粒子、无天气减产（海底无天气）。
- 场景/地图**不随昼夜变暗**（海底恒暗，靠照明道具表现明暗层次）。
