| 项 | 现在 |
| --- | --- |

| 一局能拿多少 | 采集：每天 10~20 次 → 长局 800~1500；战斗：一局 200~500；制造：一局 200~500 |

**关键约束：技能经验是"每局"的**（`S.exp` 不跨局），所以树的深度要跟"一局能拿到的经验"对齐，否则一辈子点不满。

## 1. 总体结构

每棵树 = **1 条主干（Lv1→7）+ 6~9 个分支节点（各 3 级）**，三棵树共用一套框架。

- **主干**：每升一级，从 2~3 个"成长选项"里**选一个**（制造/采集是三选一，战斗是二选一）。选择记录在 `S.skillPicks[树]`，同一个选项可以重复选（数值叠加），也可以混搭。
- **分支节点**：门槛=主干等级；花经验升 1~3 级；可带前置节点（例如"处决"要求主干 Lv5）。
- **互斥**：成对出现（每棵树 1 对）。学习前弹确认："学会《精细采集》后，本局将无法再学《粗放采集》"。

### 花费曲线（建议）

| 类型 | 花费 |
| --- | --- |
| 主干 Lv1→2 … 6→7 | `12 / 28 / 50 / 80 / 120 / 170`（合计 **460**） |
| 分支节点 1→2→3 | `30 / 70 / 130`（单节点合计 **230**） |

→ 一条树"主干满 + 2 个分支满" = **920 经验**：长局（80~100 天）刚好能做到，短局（30 天）约 300 经验 ≈ 主干 5 级。
→ 三条树要"全都练满"需要 2700+ 经验，属于超长局目标，**不会一局就无脑满**。

- 一张 3×3 图 = 9 个图标（1024×1024 → 每格 341px），**黑白木刻**风格（跟游戏一致，深色底上看得清）。

- 缺图自动回退到一个默认符号（不裂图）。

## 6. 存档兼容（红线，**不动 99% 玩家的存档**）

1. 只**新增**字段，不改老字段语义：
   - `S.tree = { v:2, gather:{}, craft:{}, combat:{} }`（节点等级）
   - `S.skillPicks = { gather:[], craft:[], combat:[] }`（主干每次升级选了什么）
2. `S.skill` / `S.exp` 继续当"主干等级 / 经验池"，老代码里的 `craftLv()/gatherLv()/combatLv()` 全部照旧可用。
3. 老存档迁移（读档时一次性、幂等）：
   - `skill.combat=3` → 主干 3 级，`skillPicks.combat = ['atk','atk','def']`，并保证**折算后总属性不低于**旧值（旧 3 级 = +3攻+3防，新 = +2攻+1防 → 差值折成额外的一次性加成券，弹一次说明）。
   - 采集 / 制造：旧效果（+10% 产出 / -8% 耗时）按等级自动填进 picks（熟手 / 迅捷）。
   - 分支节点视为未学，门槛从当前主干等级算起；经验池原样保留，**不扣不送**。
4. 互斥判定只对新学的节点生效，**不会**让老存档出现"两个互斥节点同时已学"的死状态（迁移出来的只有主干 picks，不含分支）。
5. 回归断言：老存档（构造一份 v1.06 存档）读入后：等级不掉、经验不少、按钮不少、数值对比 ≥ 旧值。

## 7. 平衡与验证

- `回归测试\checks.js` 新增断言：
  - 每个节点都有 `id / name / icon / 门槛 / 花费 / 效果文案`；
  - 互斥**成对且对称**（A 互斥 B ⇔ B 互斥 A），且互斥双方不能同时 >0 级；
  - 门槛 ≤ 主干上限；花费曲线单调递增；
  - 图标文件都存在、尺寸正确；
  - 老存档迁移断言（§6.5）；
  - **效果真的生效**：逐节点构造场景做数值对比（例：伐木专精 3 级 vs 0 级，砍 200 次的平均产出差 ≥ 阈值）。
- `开发工具\检查\_sim_skill.js`：模拟"一局典型经验投入"，输出每种 build 能点到哪、DPS/产出/耗时的相对强弱，用来发现"某棵树明显超模"。

## 9. 需要作者拍板的 6 件事

1. **主干等级**：原 5 级 → 建议**7 级**（不然分支节点没地方挂）。要保持 5 级吗？
2. **分支数量**：每棵树 6~11 个，三棵共约 28 个。够玩吗？要更多/更少？
3. **互斥能否洗点**：建议**每局每棵树可重置 1 次**（退回 50% 已花经验）。或者完全不给洗点（选择更重）？
4. **技能经验要不要跨局**：现在每局清零。树变深之后，是否让"主线等级"像魂点一样跨局继承一小部分？（会明显影响节奏）
5. **战斗主干的老属性**：老玩家"每级 +1攻+1防"要不要原样保留（新树按 1攻+1防 折算）？还是严格按你说的"每级 +1攻 或 +0.5防"（老玩家会有一次折算补偿弹窗）？
6. **图标风格**：黑白木刻（推荐，跟全游戏统一）还是彩色（像神弓 / 彩绘卡面）？

# 10. v2 定稿（作者 2026-09-17 二次确认）

## 10.1 遗忘技能（新功能）

- 加一个**遗忘**按钮：**只能遗忘技能树的"最末端"**（没有任何已学节点挂在它底下 / 它是当前最外侧的那个）。
- 忘掉之后，它里面那一层就变成新的末端，可以继续往里剥。
- 返还 **1/2 已花经验**（向下取整），日志写明"返还 X 经验"。
- 主干（Lv1→7 那条线）**不算末端节点，不能遗忘**——否则等于免费洗点。

## 10.4 横扫 CD 改成"时间制"

作者原话："CD 20→18/16/14 不是出手次数，是时间机制……攻速是每 100 秒攻击次数，cd 是秒数，
只在后台计算，游玩时不用干等，这个秒是指一个时间单位。"

实现口径（**作者 2026-09-18 最终确认**）：**攻速 = 每 100 时间单位的出手次数**（出手间隔 = `100 / 攻速` 时间单位）；
横扫 CD 按同一套时间单位计，**基础 20 秒，每级 -2 秒 → 20 / 18 / 16 / 14**。
战斗里按"每次出手推进的时间"扣（例：攻速 6 的大剑一次出手推进 16.7 秒 → CD 20 秒大约两次出手就能再扫）。
（觉得太频繁/太稀疏就改 `SWEEP_CD_BASE` 这一个常量。）
