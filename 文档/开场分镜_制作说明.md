# 开场分镜（新存档专属的 5 格漫画）

作者 2026-09-17 的要求：**每次开新存档**开头加几格画面，讲清楚来历 ——
听说亚克兰蒂斯遗址的传说 → 出海 → 遇特大风暴 → 被海水淹没晕过去 → 醒来在荒岛。
**只在开新存档有，其他情况没有。**

## 触发规则（重要，别改坏）

| 入口 | 会不会播 |
| --- | --- |
| 新的旅程 → 选存档槽 → 选身份 → 选难度 | ✅ 播 |
| 继续上次游戏（`Game.load`） | ❌ 不播 |
| 备份 · 读档 / 存档槽读档 | ❌ 不播 |
| 结局界面「重新开始」 | ❌ 不播（那里没走 `begin()`） |

实现只有一个开关：`ui.js` 里 `let freshRun = false`。
**只有 `showDifficulty()` 点难度那一下**会 `freshRun = true`，`begin()` 里消费一次就清掉。

顺带改的：读档 / 继续上次游戏**不再重复弹**「第 1 天 · 海难」那张卡
（以前每次打开存档都要再点一次「从沙滩上爬起来」）。那张卡现在只在新存档、分镜播完之后出现。

## 5 格内容（`js/ui.js` 里的 `COMIC` 数组）

| # | 小标题 | 画面 | 图 |
| --- | --- | --- | --- |
| 1 | 传闻 | 码头酒馆，老水手指着海图上的沉城 | `assets/img/comic/1_legend.png` |
| 2 | 出海 | 小船离港，帆吃饱了风 | `2_setsail.png` |
| 3 | 风暴 | 巨浪压向小船，闪电劈下来 | `3_storm.png` |
| 4 | 沉没 | 沉进黑水，伸手去够最后一点光 | `4_sink.png` |
| 5 | 醒来 | 趴在湿沙滩上，远处一座雾中的岛 | `5_wake.png` |

每格都带一个 `fb`（回退图）：万一 `comic/` 里的图丢了，自动换成已有场景图，绝不留白屏。

## 交互

- 点画面任意处 / 点「继续 ▶」/ 空格 / 回车 / ↓→：下一格；最后一格是「爬上沙滩 ▶」。
- 「跳过」或 Esc：直接进游戏，并在日志里留一行「（开场分镜已跳过）」。
- 每格：图片淡入 + 15 秒极慢推近，文字重新淡入（`comicFade` / `comicZoom` / `comicTextIn`）。
- **防误翻**：分镜出现后的 350ms 内忽略点击（开这一页的那一下不能顺手翻一格，
  和「弹窗防点击穿透」是同一套理由 —— 玩家反馈过的"单击直接睡俩小时"）。
- **省内存**：只预加载下一格，5 张不同时解码。加载画面那 2.4 秒里先拉前两格。
- 灵灰（彩色角色）走冷蓝调：`#comic-screen.lk` 那套滤镜，跟她在游戏里的表现一致。

## 图是怎么来的

```powershell
$env:DASHSCOPE_API_KEY='sk-...'
node 开发工具\生成\_gen_comic.js            # 百炼 qwen-image-3.0，1536*1024，串行（并发会 429）
python 开发工具\生成\_shrink_comic.py        # 裁掉印张纸边 + 缩到 1280 宽 + 转灰度
```

- 原图（1536×1024，约 3.2MB/张）备份在 `归档\素材实验\开场分镜原图\`。
- 进游戏的图：1280×826、灰度 PNG、741~879KB/张，合计 **3.8MB**
  （和现有全屏图同档：`map.png` 605KB / `forest.png` 712KB）。
- 出图会自带一圈印张纸边（实测 22~43px @1536 宽），`_shrink_comic.py` 里 `TRIM = 46` 统一裁掉。
- 想重出某一格：`$env:COMIC_ONLY='3'`；强制重出：`$env:COMIC_FORCE='1'`。

## 自检

  四步，并把第 1、3 格截图到 `开发工具\检查\_out\`。
