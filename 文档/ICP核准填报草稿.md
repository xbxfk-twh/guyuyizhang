# 《孤屿遗章》ICP 核准填报草稿

## 游戏内容介绍

《孤屿遗章》是一款以孤岛生存和海底遗迹探索为主题的横屏文字生存小游戏。玩家从海难后醒来，通过采集资源、制作工具、搭建营地、烹饪和交易维持生存，管理生命、体力、饱食、水分、精神和健康。探索过程中可与怪物战斗、接受委托、寻找遗物并达成不同结局。

## 联网功能与用途

- TapTap 云存档及备用存档服务用于同步和恢复进度。
- 临时取件码用于跨设备迁移存档。
- 联网兑换服务用于校验游戏兑换码并发放奖励。
- TapTap 激励视频用于玩家自愿观看后领取游戏奖励。

## 填报时核对

- 应用 ID 为 921745。退审版本 V-20261103，包体 445272。
- 从开发者后台的「资质认证 → ICP 核准信息」进入，以实际表单要求为准。选择与计划上线内容一致的包体。
- 按实际情况填写著作权人、负责人及身份资料。后台生成核验码后，由负责人扫码核验，并留意后续核验短信。
- 核准通过后，重新打包包含状态栏图标修复的版本并提审。
