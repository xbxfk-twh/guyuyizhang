# 重构验收与 GitHub 入口

本轮继续执行整体重构并同步可复核源码。当前结果是渲染与存储基础更容易独立验证；全代码重构尚未完成，也不承诺不存在其他缺陷。

## 当前代码做了什么

- UI 通过稳定节点提交更新，保留同页窗口、滚动、图片、输入和动画对象；真实场景切换继续沿用原淡入。
- 点击/长按、面板暂停与返回策略独立；食之包的选择规则、迁移、小时结算和视图已完整迁移。
- storage 下分离主档/账号读写、滚动备份、cookie 恢复、联合写入事务、存档码编解码和迁移步骤。Game 保留原 API 代理，旧实现已撤出。
- 归一化按 defaults → legacy → session → durability → toolkit → lottery-ledger → nightmare-ledger → pending-loot → food-expiry → balance 执行。主档、槽位、导入和救援沿用同一条流程；原存储键、字段含义及收据不变。
- core/session 独立记录 panel 与 host 两个暂停原因。关闭面板不解除安卓后台暂停；这些运行时原因不写入存档。
- 运行 HTML、逻辑测试与打包工具共用 runtime-manifest。GitHub 自动检查覆盖核心与重点浏览器路径。

## 账号恢复边界补强

收尾检查复现旧问题：账号主档是合法JSON但为数组/字符串/数字/布尔值时，原读取器可能把有效备份置之不理或崩溃。主档与cookie现都要求对象根节点，错误原文留底并回退备份；保存时也不把错误根节点覆盖到有效账号备份。新增3项回归，含主档写入失败时最后有效备份仍原样保留。有效档的160组写盘对照继续一致。
