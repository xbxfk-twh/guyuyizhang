# 低成本只读复核

主流程先在本地检索、运行定向测试，再把必要代码片段交给 DeepSeek 复核。关键存档逻辑与最终修复仍由主协作者验证。不能保证更换模型效果完全等同，采用可复现用例和测试控制质量。

## 使用

将筛选后的问题和源码片段写到被Git忽略的 `回归测试/_out/review-request.txt`：

```powershell
python -X utf8 开发工具/检查/_deepseek_review.py 回归测试/_out/review-request.txt --name review-result --max-output 1800
```

- 官方DeepSeek接口，模型deepseek-flash，不自动上传整个项目、不读取私有交接档案、不执行回复。
- 单次输入最多60KB，输出最多6000 tokens，默认2400。没有自动重试和循环调用。
- 凭据优先读DEEPSEEK_API_KEY，否则读本机 `%LOCALAPPDATA%/Guyuyizhang/deepseek.key` 的Windows DPAPI密文。密文只能由原Windows用户解密；不要复制到仓库。
- 报告和服务返回用量记入 `_out/<name>.md`、`_out/deepseek-usage.jsonl`；额度判断需要查询Codex用量工具，DeepSeek调用不能改变Codex账户额度。
