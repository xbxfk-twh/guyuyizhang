# 孤屿遗章 · 全商店价格表（含浮动区间）

> 由 `开发工具\生成\_gen_shops.js` 从 `js/data.js` + `js/ui.js` 现算，公式与 `js/game.js` 的 `priceOf()` 一致。

## 一、价格是怎么算出来的

```
你买进   = 基础价 × 季节系数 × 声望折扣 × 浮动(90~110%)
你卖出   = 基础价 × 季节系数 × 0.7（商人收购折扣）× 冬季溢价 × 浮动(90~110%)
```

| 影响因素 | 取值 | 说明 |
|---|---|---|
| **季节** | 春 0.9 ／ 夏 0.9 ／ 秋 1.0 ／ **冬 1.2** | 冬天东西最贵 |
| **声望折扣**（只影响你买） | 声望 0 → ×1.0 ／ 1 → ×0.95 ／ **≥2 → ×0.9** | 名声大了商人给折扣 |
| **商人收购折扣** | ×0.7（固定） | 不会因为卖得多继续跌 |
| **冬季溢价** | 兽皮 ×1.5（只有它标了 winter） | 冬天卖兽皮最划算 |
| **日浮动** | 90 ~ 110%（按"物品 id + 当天"哈希） | **同一天同一件货看多少就是多少**，换天才变；不是每次打开都跳 |

于是极值系数区间是：**买入 = 基础价 × 0.729 ~ 1.32**，**卖出 = 基础价 × 0.567 ~ 0.924**（兽皮冬天最高 1.386，实价按游戏分步取整）。

## 七、不走波动的固定定价

| 项目 | 价格 | 说明 |
|---|---|---|
| 金币 → 贝壳 | **1 金币 = 30 贝壳** | 老潮面板「金币兑贝壳」，不限次数 |
| 对岸 · 神秘货郎（奇遇，一次性） | **30 金币 → 随机 1 件未拥有的神物** | 在盐镇附近遇到，选「成交」；不是老潮面板里的常驻兑换 |
| 洞穴神龛（奇遇） | 免费 → 随机 1 件未拥有的神物 | 山洞里摸到发光的石龛 |
| 深海售卖机（亚克兰蒂斯） | **1200 贝壳币 → 当天上架的神物** | 每天刷新 1 件，亚特兰蒂斯之种不上架 |
| 修复潜水装备 | 深珊瑚 ×2（不花钱） | 礁石栖息地的修补台 |
| 校准 / 修复手枪 | 源矿×1 / 源能晶石×1 + 源质锭×1 | 同上 |
