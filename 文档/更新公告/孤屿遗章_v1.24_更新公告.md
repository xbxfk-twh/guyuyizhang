# 孤屿遗章 · v1.24 更新公告

> 本次是**集中修缮版**：把玩家反馈的问题从数据层到界面层全部过了一遍，并补齐了几处一直悬着的内容缺口（施肥、淬毒、图纸体系）。同时做了一次全局回归测试。

## 🐞 重点修复

- **采集遇袭彻底修好**：之前"把遇袭判定挪到采集结算之后"的改动留下了变量作用域错误，导致**任何采集都会抛出异常**——遇袭从来不触发、采集完界面也不刷新。现在产出照拿，遇袭正常进战斗。
- **同名多件装备的耐久彻底重做**：以前造多件时耐久只记一条，用坏一件时又会重复删除，件数与耐久记录错位，表现为"一把断了另一把也消失""新造的耐久直接变成最低值"。现在**一件一条独立耐久**，用坏哪件删哪件，背包逐件显示；旧存档读入时会自动整理。
- **结局 S2「深海长眠」补上插画**（此前该文件缺失，结算时会空一块）。
- **海图价格修正**：界面和 NPC 台词都是"三百金币"，数据里却是 150，现在统一为 300。
- **酒馆情报面板不再漏货**：改为直接读取商店数据生成列表，深海装备图纸等不再凭空消失。

## 🌱 农场与材料

- **新增施肥系统**：耕地面板每块地可「施肥（腐烂物×2）」，该地块收获 **+50%**，一块地只能施一次。
- **种地收成提高**：每次收获统一 **+2**（萝卜 4~5、小麦 5~6、药草 4~5，施肥后再翻半倍）。
- **船木终于有用了**：**大船 +船木×3**、**远洋船 +船木×5**。
- **牛角终于有用了**：新增**牛角护符**（防御+2，耐久 70），配方 牛角×2 + 绳索×1 + 兽皮×1。
- **蛛丝终于有用了**：纺车新增「纺蛛丝」蛛丝×2 → 布×1。
- **海盐修正**：晒盐原本产出的是另一件没人能用的"海盐"，现在直接产**盐**；旧海盐可卖给杂货商。
- **蝎毒终于有用了**：新增**淬毒剂**（蝎毒×1 + 树脂×1，研钵制作），战斗中使用可淬刃——**接下来 3 次命中让敌人中毒**。
- **敌人持续伤害实装**：中毒每回合 -4、流血每回合 -5。此前磨刀石的"血槽"流血只是写在敌人身上，从未被结算。

## 💰 交易体系重整

- **每个交易点有了自己的货架**：老潮（远洋杂货 + 不死丹方）、盐镇杂货商、盐镇铁匠（**高炉图纸**唯一来源）、盐镇情报贩子（**海图 / 远洋船图纸 / 深海装备图纸**）、沉船湾黑市（火药 / 解毒剂 / **硝石 / 硫磺** / **玄铁武器图纸**）、亚特兰蒂斯遗失的交易机（源质与珊瑚装备图纸）。
- **玄铁武器图纸不再两处卖且价格不一**，统一由黑市独眼 400 贝壳币出售。
- **图纸只卖一次**：所有商店与批量购买都做了硬性限制，一张图纸只会进账一份。
- **批量购买补齐**：老潮那儿原本没有长按批量，现已补上；所有商店都支持**长按购买按钮**批量买入（按你身上的货币自动算上限）。顺带修好了亚特兰蒂斯交易机批量购买点了没反应的问题。

- **珍珠来源**：近海新增热点**退潮礁石 · 撬牡蛎**（需一把匕首，每天 2 次，40% 出珍珠），配合原有的鲨鱼掉落。
- **亚克兰蒂斯装备图纸 5 张**：珊瑚刺刃 / 珊瑚甲 / 推进器 / 源质长枪 / 源质重甲，均由沉没之城的**遗失的交易机**出售（400~820 贝壳币）。
