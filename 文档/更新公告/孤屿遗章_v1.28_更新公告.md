# 孤屿遗章 · v1.28 更新公告

> 本次是**内容 + 平衡 + 一堆体验修复**的版本：新增两种体力药、精神终于有重量、深海有了拦路的怪，商人买卖和手机端批量交易彻底理顺。

## 🧪 新增物品

- **蓝牛（体力药水）**：淡水×2 + 草药×3 + 蜂蜜×1，在**药炉**炼制。体力 **+70**、水分 **+30**，代价是**精神 −10**。
- **张老吉（前期版）**：淡水×2 + 草药×2，在**灶台**（要陶锅）煮。体力 **+30**、精神 **−10**，不用蜂蜜，前期就能喝。
- 制造面板新增**「药品」页签**（研钵 / 药炉 / 灶台），草药膏、解毒剂、淬毒剂、不死丹、提神茶、蓝牛、张老吉都在这一页；原来的「家具制造」改名「加工台」。

## 🧠 精神终于有重量了

精神不再只是个数字，它直接决定你的体力上限：

| 精神 | 影响 |
|---|---|
| ≥50 | 体力上限 100% |
| 20~49 | 体力上限 **−10%** |
| <20 | 体力上限 **−20%**，且**采集耗时 +10%** |

所以药水可以当"透支"用，但连喝会越喝越虚（属性面板和顶栏徽标都会提示）。另外**肉汤和炖肉不再回复精神**（野菜汤、爆炒野菜、蜂蜜水保持原样）。

## 🥟 不死丹调整

- 吃下去回血 **100 → 60**。
- 倒下时保住 **50 → 30** 点生命。
- **同一局最多炼制 3 颗**（第 4 颗在制造面板会直接锁住，并显示"本局已炼 X/3"）。

## 🌊 深海 / 亚克兰蒂斯

- **深海区移动会被拦**：在珊瑚森林、珍珠洞窟、沉船墓地、海沟、深渊裂谷、深水圣殿之间游动，**40%** 概率被深海卫兵 / 触手哨兵 / 机械守卫拦下。移动（时间、体力、到达）照常结算，打不打都不会白跑。
- **遗失的交易机**每天随机上架 1 件**神物**，1200 贝壳币，当天买走就售罄（亚特兰蒂斯之种不参与随机）。
- **每场战斗最多使用 2 次道具**（以前计数没生效，等于可以无限喝药）——按钮会显示"道具（2）"，用完置灰。

## ⛰️ 山顶与稀有资源

- **雪莲 / 秘银新增拦路**：采摘各有 **50%** 概率撞上**石板守卫**，可以选「不采了，直接跑」（不扣当日次数，只花 10 分钟）或「殊死一搏」（打赢了接着采）。它掉金币和玄晶，**不掉石板**（避免刷钱）。
- **鹰巢失手不再只是掉血**：会直接招来雪羽鹰，打赢照样掉鹰羽。
- **发光苔藓出水晶 15% → 25%**，望远镜和手电不那么看脸了。

## 💰 交易大改

- **金币兑贝壳 100:1 → 30:1**（卖给商人的金币单价同步下调，避免套利）。
- **收购价恒定八折**：以前是"卖得越多越便宜、还一直不跌回来"，现在改成商人一律按行情八折收，**卖 1 个和卖 500 个单价一样**，跨天也不变。
- **批量买卖**：老潮、盐镇三摊、黑市、交易机的买/卖全部支持**长按批量**；手机端专门做了加固（滑动取消长按、系统打断不误触、禁用按钮不响应），批量条还新增「1 个 / 一半 / 全部」快捷档。
- **批量购买全量排查**：六家货架 32 件货逐件验证都能一次买满；钱不够时批量上限自动等于"买得起的数量"，不会点了没反应；用金币标价的海图也能正常批量结算。
- **图纸长按也会弹批量条**（数量锁 1，并标注"图纸只需一份"）——以前长按没反应，容易被当成"批量购买不生效"。
- **修掉交易机的一个跳转 bug**：在亚克兰蒂斯交易机批量买完东西，以前会莫名其妙跳回盐镇集市，现在正确回到交易机界面。
- 批量条新增**单价 + 实时合计**：拖动数量条时合计跟着变，买多少花多少一眼看清。

## 🏴‍☠️ 海盗船长改成"每 5 天一班船"

第 20 天起，只有**天数是 5 的倍数**（20、25、30……）才能在海域遇到海盗船长。不是刷新日点它会在日志和屏幕上提示：**"海面上今天没有船影——下一次是第 X 天。"**

## 🐞 这轮修掉的 bug

- **熏鱼图标底部被截断**：是从多格图裁切时带进了邻居的碎片。顺着一查，**烤鱼、肉干、化石、钢镐、铁匕首、玄铁镐、船木**都有同样的毛病——共 **8 个图标**全部重做。
- **蓝牛 / 张老吉 图标偏小**：抠图时把一大圈空气一起缩了进去，现在和同排药瓶一样大。
- **亚克兰蒂斯大地图最上面两个箭头被裁**（返回孤岛 / 珍珠洞窟）：现在会按实际位置自动翻成"箭头在上、标签在下"，矮屏幕也不会缺角。
- **砍树彩蛋日志写着"美人松木材×7"**：看起来像另一种材料，现在直接并进"木材"数量里。
- **交易机收购价显示的是基础价**，和实际成交价不符 —— 现在显示真实价格。
- **点到不能用的点位只提示"现在做不了这件事"** —— 现在会写清具体原因（缺火把、太黑、工具等级不够、季节不对、没到刷新日……）。
- **鸡舍 / 羊圈的每日产出看不见也没保障**：以前它们是**静默入包**的，背包一满产出就悄悄没了，玩家只会觉得"我的羊毛和肉呢？"。现在每天会明确写日志（「鸡舍有产出：兽肉×1」「羊圈有产出：羊毛×1」），**背包装不下时会记成"待收"，腾出空间后次日自动补发**，不会再凭空消失。

## ⚠️ 更新前请先导出存档码

存档是存在浏览器本地的，**换链接后旧记录不会自动跟过来**。更新前请到「备份 · 读档」面板导出一次存档码，换环境后粘贴导入即可恢复魂点、成就、图鉴与备份槽。

> 另外提醒一句：恒定八折意味着卖价比原来"第一次卖"低 20%，木材这类便宜货几乎不值钱了。如果觉得手太紧，下一版可以把折扣放宽到八五折 / 九折。
