## 审计结论

以搜索 + 局部读取证明问题，不做按长度的机械拆分：

1. **重复的饰品/命名/磨刀石取数**：`S.equipment.accessory && ITEMS[...].atk/def/hp` 这一串在 `playerAtk / playerAtkAvg / rangedAtk / charStats / playerDef / hpMax` 抄了 6 遍；`S.weaponSharpen && S.weaponSharpen.am` 在 4 处内联（`sharpenAm()` 早已存在却没被用）；`S.weaponNames[id].bonus` 在 3 处各写一遍。
2. **R 魔法值易失配**：`HOUR_EFFECTS` 里把「22 点～6 点算夜间」又内联了一遍 `S.minute >= 22*60 || S.minute < 6*60`，与全局 `isNight()` 两处散落；看天气/精神/赶路/travelCost 都在用 `isNight()`，唯独时间流逝这一份自抄。
3. **真 bug（缺 id 字段的武器命名加成失效）**：`nameWeapon` 按**物品键**存 `S.weaponNames[id].bonus`，但 `playerAtk/playerAtkAvg/charStats` 却按 `cur.id / me[0].id`（ITEMS 对象自带的 id 字段）取，木棒/石矛/猎弓等在 data.js 里没有 `id` 字段，于是命名后「伤害永久 +1」被悄悄吞掉。触发条件：用命名牌给上述无 id 字段武器命名后去打怪，面板与实战伤害都不含 +1。

## 实际修改（只改 js/game.js，均为等效重构 + 一处真 bug 修复）

1. 新增纯函数 `accessoryStat(key)`，替换 6 处饰品取数（playerAtk / playerAtkAvg / rangedAtk / charStats / playerDef / hpMax）。
2. 新增纯函数 `weaponBonus(id)` 与 `itemKeyOf(it)`，替换 3 处命名加成取数；`itemKeyOf` 按装备槽反查物品键（而不是对象的 `.id`）。
3. `playerAtk/playerAtkAvg/rangedAtk/charStats` 四处改用已有的 `sharpenAm()`，删除内联的 `S.weaponSharpen && ...`。
4. `HOUR_EFFECTS` 的夜间判定改为调用全局 `isNight()`（局部变量改名 `nightNow`，避免 TDZ 遮蔽）；删除内联的 22 点/6 点魔法值。
5. **真 bug 修复**：命名加成现在按 `itemKeyOf(...)` 读取，无 id 字段的武器（木棒/石矛/猎弓等）命名后 +1 伤害真正生效。其余玩法数值/文字/存档字段语义/版本号一律未动。
