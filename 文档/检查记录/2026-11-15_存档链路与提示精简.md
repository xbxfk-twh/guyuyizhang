[Kittens Game 的历史丢档复盘](https://www.reddit.com/r/kittensgame/comments/ebjj37/kittens_game_save_wipe_postmortem/)记录了移动 WebView 数据在系统/浏览器更新后不可见的问题，并提出额外存储和云备份计划。这是历史事故说明，不代表我们已复现该事故，也不据此宣称新存储绝对安全。

这些是设计参考，不能证明浏览器、系统清理或服务故障时绝不丢档。正常时安静运行，实际失败时保留原文、明确反馈，是本次采用的原则。

## 审查范围与保留边界

| 链路 | 实现及结论 |
| --- | --- |
| 内存状态、初始化、读写装配 | `core/state-store.js`、`game.js`、`storage/service.js`。SaveService 已统一端口；保留仓库与事务分工，不再合并成一个更大的文件 |
| 普通保存、账号与旧镜像 | `storage/repository.js`。主档有效时优先主档，备份其次，cookie 最后；读失败不当空档，坏主档不能覆盖最后有效备份。保留写后读回校验、账号修订与标签页保护 |
| 导入及账号/本局成对更新 | `storage/transactions.js`。失败恢复内存与原持久化键；尚有未完成日志时拒绝新事务。仓库内层不再重复通知，外层回滚后统一通知 |
| 平台文件、Tap 云、自有服务备用 | `storage/platform.js`、`storage/server.js`。保留设备双槽校验、启动核对、另一份进度留存、配额差量事务、服务器版本比较及限频；未改服务协议或读取优先级 |
| 文件/临时码 | `storage/codec.js`、`storage/transfer.js`、`features/account.js`。保留校验、预览、永久升级/结算历史保护；仍为八位取件码、十分钟、每小时三次。改为玩家点击生成或下载时编码 |
| 旧字段迁移 | `storage/migrations.js`、`core/session.js`。不改字段名和语义，不以静态引用次数删迁移；包括账号、蓝图、负面状态等历史数据 |
| 手动槽、开新局留存、日出回溯 | `features/save-slots.js`、`features/lifecycle.js`。它们有不同的玩法及恢复语义，不能当重复备份删掉；保留费用、结算防重复和覆盖确认 |
| 玩家界面与生命周期 | `ui.js`、`ui/views/startup.js`、`render.js`、`title.js`、`dialogs.js`、`progression.js`、`index.html`。核对继续、保存、备份、扫描、预览导入、启动诊断、后台保存和定时保存路径 |
| 安卓宿主 | `安卓包装/app/src/main/java/top/guyuyizhang/game/MainActivity.java`。固定资源域名、暂停前保存和失败不退出仍保留；文件接口存在时恢复手机文件按钮，纠正旧长码提示 |
| 独立备用服务 | `开发工具/存档服务/server.py` 及对应隔离测试。历史快照、CAS、身份认证、临时取档与限流有实际用途；只做源码与隔离测试核对，没有连接生产环境或修改数据库 |

暂不退役：cookie/旧文件解码、事务 v1 与平台差量 v2 恢复、旧 SAVE 取档协议、线上备用接口。当前没有证据证明旧客户端、未完成事务和玩家持有的历史文件已全部退出使用。退役需有客户端使用范围、旧文件转换和回滚验证依据，不能只依据新界面已不显示长码。

## 实际修改

- 删除“历史崩溃计数达到阈值即弹安全模式”的整条路径。成功核对存档并画出标题后直接进入；旧计数键不再读写，也不主动清理玩家存储。
- 删除每次成功渲染时的三次计数/启动标记写入。实际错误仍记录精简诊断，界面渲染失败提示不再暗示存档损坏或要求回档。
- 自动保存失败改为非阻塞提醒，同一页面三十秒内最多一条，保留原始错误记录。明确点击保存/退出时仍反馈失败且保持页面，不显示技术异常名，不假报成功。
- 成对事务内只由外层失败处理通知，仓库不重复通知；失败后的强制覆盖不再记录“已覆盖成功”，仍可重试。
- 单纯等待超过三十秒改为“加载较慢，可以继续等待或重试”。真实脚本、账号读取或初始化错误仍有重试、诊断和原始备份；不把读取错误当成首次账号。
- 备份页用“恢复本机备份”及简短说明；没有扫描结果时说明可使用文件或有效取件码。扫描、源列表、覆盖前确认均保留。
- 打开取件码页不再生成/解析一整段大载荷，生成与下载才取当前内存进度，避免展示时重复编码及页面打开后数据陈旧。
- 手机网页继续隐藏不可用的文件按钮；具有完整 `GuyuFileBackup.save/open` 原生接口的 APK 提供文件导入导出。新增提示有英文翻译。
