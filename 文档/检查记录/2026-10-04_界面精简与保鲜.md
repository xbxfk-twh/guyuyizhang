# 界面精简、保鲜与数值调整

源码已修改；保留已有未提交工作。没有修改版本号、运行打包或上传，也没有批准新版公告。

## 界面与交互

- 攻略、邮箱移入菜单，邮箱入口保留未读数；菜单移除重新开始。当前目标默认关闭，已有玩家主动开启的设置保留。
- 温度、正面增益和负面状态统一显示在场景右上角。返回地图、日志开关上移，地点介绍放在它们右边；修复返回按钮被状态栏遮住的问题。海底不再重复提供右下角大地图入口。
- 设置增加“场景上下滑动”。默认沿用开启；关闭后小场景按当前屏幕压缩，地图采用完整显示，热点坐标随画面一起适配。日志、背包和商品列表的独立滚动不受影响。
- 手机制造按钮由约 44px 降到 29px，保留名称、材料和批量入口。
- 移除“听一句”，点击商人卡面即可听其台词；键盘也可操作。取消切换场景、返回地图、打开制作入口及切换皮肤时的重复提示音，保留操作结果音效。
- 交换机数量最低 1，快捷档为 1/10/100/全部；次数最低 1，快捷档为 1/10，移除 0/25/50 快捷按钮。库存、日限和每批 50 次的后台限制保留。
- 活动小广告放在底部，命名牌提示和邮箱规则说明精简。游戏内撤下所有 v1.10 以前的公告及其旧公告邮件，物资邮件保留；v1.10 草稿仍未批准。
- 两处攻略更新工具材料、传奇背包、基础作物产量及生食风险，删除“种地统一 +2”的旧说法。

## 食品与制造

- 同名易腐食品在背包中仍合堆，但新增 `foodBatches` 保存各批数量和原到期时间。新做的超级大蛋不再继承旧批的短保质期；食用、出售、作材料时优先消耗早到期的批次，过期也只腐烂到期批次。
- 老档仅有 `foodExp` 时，原有库存按原期限迁移；兼容标量字段继续保留。未修改原有基础保鲜时长及晾肉架加成。
- 制造材料增加 `craftRemainders` 记录不足一份材料的余额。流水线为材料 -40% / 耐久上限 -20%；精工细作为材料 +30% / 耐久上限 +30%，只影响带耐久的产物。一份材料的配方做十件分别耗 6 / 13 份，单做和批量一致；余额可随存档保存。
- 精算返还按实际扣料封顶，避免折扣后批量返还超过支出。产物容量检查、失败返料、原有耐久上限及旧档兼容保留。

|---|---|
| 石斧、石镐 | 木材×2、燧石×2 |
| 铁斧、铁镐 | 铁锭×2、木材×2 |
| 钢斧、钢镐 | 钢锭×2、木材×2 |
| 玄铁镐 | 玄铁锭×2、木材×2；原图纸与工位条件保留 |
| 锄头 | 木材×2、石头×2 |
| 鱼竿 / 陷阱 | 竹×3、藤蔓×2 / 木材×3、藤蔓×3 |
| 药草种植 | 未施肥基础 2～3；不再乘难度资源倍率，原施肥 +50% 保留 |
| 生鱼、生兽肉 | 20% 反胃；游戏时间 12 小时内主动体力消耗 +50%，向上取整 |
| 传奇背包 | 未造初级箱子基础 12 格；造箱后基础 20 格。旧档的特殊容量及其他扩容加成保留 |
| 烤鱼回收 | 美食家基础价 6 → 8，与老潮一致 |
| 秋季甜点委托 | 三个蛋糕换 270 贝壳币及 0.5 声望，沿用当季随机委托规则 |
| 海底源矿 / 源质锭 / 发光远古装置 | 基础价统一为 40 / 260 / 120；海底交易机与对岸一致，源矿可单独回收 |
| 腐烂物 | 商人不再收购，肥料制作等用途保留 |

商人实价仍按季节、声望、收购折扣和每日浮动计算；260 是基础价，不是承诺每次卖出拿到 260。源质锭需源矿×2和装置×1，成品基础价高于原料合计 200，保留加工价值。

## 遗海交换机

- 常规随机出奖率仍最高 2.05%，保留每日 200 次、稀有奖门槛和神弓唯一性。
- 连续未出奖投入价值累计 **6000**，当次保底一颗不死丹、潮生丹或渊息丹。单次计入价值仍最多 5000；这不是 6000 次抽取。
- 任何奖品，包括蜂蜜，都会同时清空储能和保底累计。界面显示保底进度，下一次达到保底时明确显示“首次保底丹药”。
- 保底放在账号级同局记录；导入旧存档码或云档时按较新抽取序号保留完整记录，不能用最大保底值合并，避免把已清零的进度恢复。保留本机已用兑换码及神弓唯一标记。
- 先成对持久化投入、结果及账号记录，再播放动画；磁盘失败保留回滚机制。
