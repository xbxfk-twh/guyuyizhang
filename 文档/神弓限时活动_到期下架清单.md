## ⚠️ 删除后必须同步改的检查（否则自检会红）

删掉配方后，`回归测试/checks.js` 里这几条会失败，需要一并处理：

**搜索**：`RECIPES.find(r => r.id === 'r_divinebow')`

- `ck('神弓耐久 50、带 divineCrit、配方标「限定」且带 uniqueItem', ...)` → **改成**只验物品与耐久（把 `REC && /限定/.test(REC.name) && REC.uniqueItem === BOW` 这几项去掉）
- `ck('神弓配方材料跨多线（...）', ...)` → **整条删掉**
- `ck('实测：条件是齐的时候可以做', ...)` 和 `ck('实测：做出来是神弓×1', ...)` → **改成**"活动结束后配方已下架"（断言 `!RECIPES.some(r => r.id === 'r_divinebow')`）
- `ck('实测：★ 身上有一把就不再显示/允许制作', ...)` 与 `ck('实测：★ 邮箱里有一把时同样不允许再做', ...)` → **整条删掉**（唯一性拦截随配方一起没了）
- **保留**：暴击那几条、邮箱存取那几条、耐久转移那条

同时这三个脚本里如果还有引用配方的地方也要看一眼：
`开发工具/检查/_verify_divinebow.js`（搜索 `r_divinebow`）、`_verify_bow_ui.js`（搜索 `限定 · 神弓`）。

**最省事的做法**：让 `_verify_divinebow.js` 在开头判断"配方还在不在"，不在就自动跳过制作相关的那几段，只跑"已做出的弓能不能用"。
